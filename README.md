
## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Create a production build with `npm run build` and inspect it with `npm run preview`.

## Git workflow

```bash
git init
git add .
git commit -m "Build Daymark TypeScript task planner"
```

To publish to GitHub, create an empty repository there and connect it:

```bash
git remote add origin https://github.com/<your-username>/<repository-name>.git
git branch -M main
git push -u origin main
```
